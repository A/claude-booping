The system gets better from its own runs, but only through the user and when the
user wants it: a lesson becomes a rule after the user takes it, not after every run.

## In practice

Retro and learn run when the user asks; what they propose becomes a rule only with the user's consent.

## Trade-off

Mistakes may repeat until the user runs a retro.
