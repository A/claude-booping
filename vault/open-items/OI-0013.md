# What counts as force majeure

## Question

Is "irreversible unplanned destruction or a hard harness block" the definition?

## Context

value/0007 and booping:rule/0004 let develop stop only for force majeure, "what grooming could not have known", and neither defines it. The owner's memory note says that during a develop run only irreversible unplanned destruction or a hard harness block earns a stop, and then only once, at the end.

## Proposal

Write that definition into value/0007's In practice, and have booping:rule/0004 link to it.
