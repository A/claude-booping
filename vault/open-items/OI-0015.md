# auto_migrate contradicts the migrate ADRs

## Question

Keep auto_migrate on by default and fix the two ADR lines?

## Context

adr/0017 says a vault behind the shipped migrations gets a blocking notice to run /playbook migrate. adr/0018 says migrate asks once over the whole pending set. core.auto_migrate defaults to true, so the agent runs migrate unattended and the approval renders empty. No record covers auto_migrate.

## Proposal

By rule/0034 the config key is its own source, so add no new record. Fix the two lines: adr/0017 says the notice blocks only with auto_migrate off, and adr/0018 says migrate asks once unless auto_migrate is on.
