# May an autonomous run accept a new rule without the owner?

## Question

Should an autonomous run ever activate a new rule on its own?

## Context

adr/0034 §3 lets non-value drafts, new rules included, land in an autonomous run without the owner. value/0001 says a lesson becomes a rule only after the user takes it. adr/0034's own criterion is "a draft the owner confirms".

## Proposal

In an autonomous run a new rule or a changed rule lands as a draft `[clarify]` item (status clarify) and does not take effect until the owner accepts it. Other drafts (ADR, story, reference) follow autonomy as now.
