# Autonomous review defers architecture decisions the owner delegated

## Question

Config key or project rule?

## Context

Source: [lightspace-android feedback](../notes/20261018-lightspace-android-feedback.md), point 14.

An autonomous review defers decisions "to owner" even when the owner delegated architecture. The suggestion is a config hint naming who the architect is.

## Proposal

A project-tier rule targeting code-review and project-manager states what the agent decides alone; no new config key.
