## Task type

`feature` — the default home of a project's specs moves for every user (resolution, loading, check, setup, a shipped migration), a user-visible change of where records live and what `specs check` reads. Not `bug`: nothing diverges from intended behaviour today — adr/0001 was amended, the code has not followed yet. Loading and `specs check` must then read only known-type directories of the vault root and ignore the rest of the vault.
