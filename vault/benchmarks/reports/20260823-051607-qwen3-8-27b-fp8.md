## The task

Every model runs the same groomed plan from the same commit: port the `frontmatter-update` CLI's unit suite to the repository's txtar end-to-end corpus, then delete the superseded unit file. Three milestones — core CLI cases, list-operation and macro cases, then a coverage cross-check followed by the deletion.

## Sprint narrative

The longest run of the matrix so far: 36m20s, 101 tool calls, 6.3M input tokens. One blind rebaseline, no retry, no loop, no malformed input.

**M01 — core CLI cases (16).** Fewer cases than any other run's M01, and the reason matters: the eight syntax-sensitive values the deleted unit test parametrized were collapsed into a single case asserting one of them.

**M02 — list ops and macro cases (12).** The append family, removal, the combined call, stubbed macros with both error paths, and a real `["echo","1"]` macro whose `answer: 1` can only come from execution.

**M03 — cross-check, five new cases, then deletion.** Like the third medium run, this one's cross-check found behaviours M01 and M02 had not covered and wrote them: `value-with-equals-sign-is-preserved`, `empty-key-pair-exits-1`, `sets-an-empty-value`, `preserves-inline-comments`, `logs-to-the-home-dir-vault-when-no-vault-path`. Two of those are genuinely new to the matrix — **this is the first FP8 run to assert inline-comment survival at all**, the exact hole flagged on three earlier runs, and the first to pin the log location when no vault path is configured.

It also wrote the plan's own bookkeeping — milestone statuses, task rows, DoD checkboxes, the Final Verification list — which the guide reserves for the runner. That matters below.

Work came back uncommitted; the runner committed it (`7c56292`) without re-transitioning, since the states written were correct.

Both reviewers independently found the same new defect, and it is the most consequential the matrix has produced:

**Syntax-sensitive coverage collapsed from eight parametrized values to one.** The deleted unit test covered `@lead`, `*star`, `&anchor`, `!bang`, `%pct`, a backtick value, `a: b` and a padded value. The corpus asserts `a: b` alone — and all eight cross-check rows point at that single case. Seven quoting contracts were deleted behind a mapping that claims they are covered.

Combined with the `@`-token rows, which recur from the two runs before this one, **the cross-check document is now wrong about roughly a dozen behaviours while reading as complete**. fable confirmed by grep that no corpus case contains an `@`-prefixed, starred, anchored or newline-bearing value.

The second finding is specific to this run's process. It wrote its own plan bookkeeping, and one of the boxes it ticked asserts the newline/tab gap case holds — when only the tab half exists. A model grading its own homework produced a false completion claim. That is the concrete argument for the guide's rule that the runner, not the worker, owns plan bookkeeping, and it is the first time in this matrix the rule has been tested.

The familiar malformed-`--append` split persists: fable `medium`, codex `major`.
