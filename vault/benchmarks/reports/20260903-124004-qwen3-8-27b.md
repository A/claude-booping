## The task

The benchmark hands every model the same groomed three-milestone plan at the same repo state: port `booping frontmatter-update`'s 571 lines of unit tests into a txtar contract corpus under `booping-python/e2e/cases/frontmatter-update/`, add the gap cases the units never had, then cross-check the coverage and delete the unit file wholesale. The model gets its own throwaway clone and its own branch, answers no questions, and is scored on the branch it leaves behind.

## Sprint narrative

The second of three back-to-back runs at identical settings, and the same all-at-once shape: all three milestones in one pi session, one log segment, one attempt. 16m58s across 87 tool calls — 43 bash, 34 write, 6 read, 4 edit.

M01 produced 17 cases, and one detail in it is the most interesting decision of the run: the newline-and-tab gap case cannot be written the obvious way, because control bytes cannot ride a one-line `cmd`. The session solved it by carrying the value through a stubbed macro, recording `"a\nb\tc"` double-quoted and round-tripping exactly — both halves of the gap case in one file. It also caught, during its own read-back, that an unquoted `23 things` shlex-splits, and quoted the pair so it stays a single argv element. M02 added 13 cases across the list ops and both macro paths. M03 wrote two extra mapping cases its cross-check turned up (`value-containing-equals-splits-on-the-first` and `empty-value-and-removal-in-one-call`), recorded `coverage-cross-check.md`, and deleted the unit file. 32 cases in total, and every milestone's `## Verify` passed with no case rewritten on a clean run.

The process record is spotless: no retry, no feedback file, no malformed tool input, no degenerate loop, no context death and — unlike the run before it — **no blind rebaseline**. That is the whole difference between this run's 100.0 agentic and the 75.0 the 12:17 run scored.

The runner validated the tree, confirmed `just ci` green, and made the commit; the vault bookkeeping is the runner's, applied after the sprint.

## Corpus quality

Exact-name recall was **7/34**; after the mapping judge read the bodies, **31/34** (91.18%) — the best mapped recall of the three runs. Gap coverage went from 0/3 to **2/3**. Three etalon behaviours went unported:

- `malformed-append-pair-is-rejected` — the uncovered gap case, the same one every run in this set missed. `--append noequals` exits 1 through a separately-parsed path no case reaches.
- `diff-names-the-plan-on-both-sides` and `summary-goes-to-stderr-not-stdout` — both folded into `sets-a-key.txtar` rather than given their own cases, so the milestone's claim that each behaviour has its own case does not hold for these two.

Four-channel rigour is **29/32** (90.62%), the lowest of the three runs — the two nothing-to-do cases seed a plan but list no `expected/` copy, so the "file untouched" half of their contract is unasserted. The wildcard ratio is **0.0018**, one wildcarded line in 561. One orphan case: `append-only-call-with-nothing-to-do-exits-1.txtar` runs the identical bare command as `nothing-to-do-exits-1.txtar`.

## Mutation kills
