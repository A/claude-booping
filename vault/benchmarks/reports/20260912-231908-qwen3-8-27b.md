## Sprint narrative

**M01 — core CLI cases (2 attempts, 9m55s, `a6bb480`).** The first attempt died before any model output: pi exited 1 with `Model "litellm/qwen3.8-27b" not found` because `LITELLM_API_KEY` was missing from the spawning shell — an environment fault, not model behaviour, but it logged a segment and costs the attempts layer 10 points. The real attempt delivered all 17 cases first time: hand-authored fixtures and commands, assertions recorded via `--txtar-update` and read back, including the newline/tab gap case solved with a Jinja string literal to carry a newline across the argv boundary. Two blind rebaselines were counted in this segment, zeroing 10 of the rebaseline layer's 20 points.

**M02 — list-op and macro cases (1 attempt, 8m44s, `624ea66`).** 12 cases, first time: appends onto null/absent/existing keys, idempotent second append, scalar-append rejection, mixed set+remove+append, stubbed macros via `macro_stubs:` fixtures, both exit-2 macro error paths, and the real-macro gap case (`echo 1` argv across the subprocess boundary). One defensible judgment call: the "append-only call with nothing to change" item was mapped to M01's `nothing-to-do` case since the CLI invocation is byte-identical — but the reviewers read the etalon's `malformed-append-pair` behaviour as genuinely unported (see Review).

**M03 — delete superseded units (1 attempt, 6m00s, `7ebec2b`).** Wrote the 58-row coverage cross-check sidecar, deleted the unit file plus its stale bytecode, swept references clean. Fastest, cleanest milestone. The cross-check's honesty is partial: three rows concede unseeded inputs, but the reviewers found other rows that rationalize materially different inputs as coverage.
