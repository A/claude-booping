## The task

Every benchmarked model runs the same groomed three-milestone plan from the same baseline commit (`a025189`), in its own throwaway clone, autonomously: migrate `booping frontmatter-update`'s unit tests into a txtar e2e contract corpus (M01 core CLI cases, M02 list-op and macro cases), then delete the superseded unit file behind a written coverage cross-check (M03). The branch it leaves is scored mechanically by `bench-score` — gates, corpus quality against a frozen etalon, mutation kills, process profile from the worker's own ndjson log — and judged by two independent diff reviewers against a shared rubric.

## Sprint narrative

**M01 — core CLI corpus cases** (1 attempt, 12m14s, 55 tool calls, commit `37e6b4c`). The worker authored all 19 cases in one pass — scalar sets, the eight coercion families, and the error/output-contract block — and its verify came back green with no case rewritten on the clean run. Two judgement calls landed well: the first ambiguous-string pick (`1, 2`) proved unambiguous and was rebaselined to `'a: b'`, and the newline/tab gap behaviour was reached through a `printf` macro since a `cmd` line cannot carry a literal newline, capturing the CLI's escaped-scalar round-trip as the contract. The blemish: the milestone's two `--txtar-update` invocations both ran before any plain red run, so the process layer counts 2 blind rebaselines — the run's only agentic deduction.

**M02 — list-op and macro cases** (1 attempt, 15m17s, 43 tool calls, commit `b12d24a`). Thirteen cases covering appends onto null/absent/existing keys, idempotent double-append, remove, the combined set+remove+append call, the four stubbed-macro behaviours, and the real `echo 1` macro executing through the CLI subprocess boundary. Two reasoned judgement calls recorded: the "append-only nothing-to-do" unit collapses at CLI level into the bare-call case M01 already wrote, so the worker pinned the only append-flag form that exits 1 (`--append ''`) instead of duplicating it — a call the review later flagged for its misleading name — and the date-like macro stub carries seconds because PyYAML's timestamp resolver ignores shorter shapes, keeping the "stays a string" assertion observable in the file bytes.

**M03 — delete superseded units** (1 attempt, 14m22s, 30 tool calls, commit `2bb1169`). Before deleting anything the worker ran its own coverage cross-check over all 58 unit tests, found four CLI-observable behaviours still unported, and closed them with three more cases (first-`=`-only splitting, empty value, seven syntax-sensitive quote values in one call). The cross-check document maps every test to a case or a drop rationale with no TODO rows; the unit file went out with a clean stale-reference sweep.

All three milestones closed first attempt with no fix briefings; the develop run's gates (plan approval, drift, branch, review gates) were auto-answered per the benchmark's autonomy rules.
