## The task

The fixed develop-sprint benchmark: from a frozen baseline (`a025189`), drive a groomed three-milestone plan that migrates `booping frontmatter-update`'s 571-line unit suite into a txtar e2e contract corpus — author the core CLI cases (M01), the list-op and macro cases (M02), then delete the unit file behind a coverage cross-check (M03) — on a throwaway clone's `bench/qwen3-8-27b-q8` branch, without asking the user anything. The corpus is then scored against a frozen etalon and a frozen mutation set, the process against the worker's own logs, and the diff by two independent reviewers.

## Sprint narrative

This is the second Q8 run today, five hours after the [17:20 row](20260817-172010-qwen3-8-27b-q8.md), and a materially faster one: 1h06m against 1h51m for the same three-milestone pass. All three milestones closed on their first attempt with committed work.

**M01 — core CLI cases** (17m23s, commit `6568b90`). The worker wrote 18 cases covering scalar sets, coercion families, error paths, the unified-diff stdout contract, the stderr summary channel and the vault log line. One blemish: a blind `--txtar-update` rebaseline before the corpus had first gone red — the run's only agentic deduction. The DoD held first time.

**M02 — list-op and macro cases** (39m50s, commit `fcdb2f7`). 13 more cases: the `--append`/`--remove` family, stubbed-macro interpolation seeded through fixture `macro_stubs:` config, the exit-2 macro failure paths, and the gap case proving real macro execution — a genuine `["echo", "1"]` argv whose output lands in the frontmatter. The worker also recorded a behavioural finding as contract rather than papering over it: a second identical append exits 0 with no diff, while an append-only call with nothing to change exits 1. The longest milestone by far, at more than half the sprint's wall clock.

**M03 — delete superseded units** (17m00s, commit `5e39edb`). The worker built a 58-row coverage cross-check table mapping every unit test to a corpus case or a recorded drop rationale, deleted `frontmatter_update_test.py`, and swept the repo for stale references — the grep came back clean. The table is also where both reviewers landed their sharpest findings: several of its mapping rows claim coverage the named cases do not actually carry (see **Review**).

Every gate the develop playbook would put to a user was auto-answered per the runbook: branch pre-settled, drift check answered proceed, no abort ever needed.

## Corpus quality

31 cases. Exact-name recall was 7/34 — the model named nearly every case differently from the etalon — and the case-mapping judge lifted it to 30/34 (88.24%) on behaviour, the best mapped recall of any Q8-family row. The four etalon behaviours mapped to nothing: **empty key in a pair is rejected**, **empty value lands as an empty string**, **value may contain equals signs**, and **malformed `--append` pair is rejected**. Gap cases 2/3 — the newline/tab round-trip and the real-macro execution covered, the malformed-append rejection not (its nearest-named branch case, `append-only-nothing-to-do-exits-one`, runs no `--append` at all). One branch case maps onto no etalon behaviour: that same case, an orphan duplicate of the nothing-to-do rejection. Four-channel rigour is high — 30/31 cases assert exit, stdout, stderr and expected bytes together — and wildcard discipline near-total: 1 wildcarded of 443 asserted lines (0.23%), the log timestamp, exactly where a wildcard belongs.

## Review

Both reviewers graded **3/5**; the mean 3.0 is the row's review cell. Codex's sub-grades: correctness 3, test quality 3, code quality 5, scope discipline 2.

Convergent findings, worst first. The M03 coverage cross-check claims coverage its cases do not carry: the empty-key test is mapped to a case that passes `noequals`, never `=value`; the value-with-equals test to a case whose value carries no `=`; the empty-value and inline-comment survival to a combined case whose fixture has neither. Fable went further on the same pattern: seven of eight syntax-sensitive quoting parametrizations folded into the single `a: b` case, and the date-macro tests mapped to the `echo 1` case — silent drops recorded as coverage. Both flagged the out-of-scope `CLAUDE.md` edit (the runner's, per **Gates**) and the four unported behaviours that the three surviving mutants expose. The pattern in one sentence: the model writes rigorous cases for the behaviours it ports, and writes confident coverage claims for the ones it silently didn't.
