Delivered 17 cases: scalar sets, multi-pair calls, no-op idempotency, the coercion families (int, float, bool, null, date-like strings, YAML-1.1 `yes`), three exit-1 error paths, unified-diff stdout shape, stderr summary routing, and the wildcarded `.booping.log` line. **M02 — list ops and macros (3 SP, 1 attempt, 30m, commit `c5126b5`).** Found stale M01 loop state on entry, archived it, re-planned cleanly — good hygiene for a small model. Delivered 12 cases: `--append` semantics (creates list on null/absent key, extends, idempotent repeat, rejected onto a scalar), `--remove`, the combined pairs+removals+appends call, and the whole macro surface — stubbed macros landing typed, unknown macro path exit 2, malformed Jinja exit 2, and the gap case proving a real `echo 1` macro executes across the subprocess boundary. It deliberately skipped one contract behaviour ("append-only call with nothing to change exits 1"), arguing the bare-argv case already covers it — defensible, but it marked the task done rather than flagging the gap upward.

**M03 — delete superseded units (2 SP, 1 attempt, 56m, commit `af3b102`).** Built the 58-row coverage cross-check mapping every unit test to a corpus case or a drop rationale, deleted the unit file, swept for stale references. A validator sub-agent re-ran the verify commands against the git blob of the deleted file and passed it. Slowest milestone by far — half the run — and the one where the quality problem hides (below).

## Corpus quality

- **29 cases**, vs the 34-case etalon frozen from the opus reference run.
- **Recall 28/34 mapped (82%)** — but only **7/34 by exact name**. The model renamed nearly everything (`boolean-value-lands-unquoted` → `coerces-a-boolean`), so a case-mapping judge read the 22 unmatched branch case bodies and mapped them behaviour-by-behaviour. The work exists; the naming diverges more than any other run to date except its own siblings.
- **Six etalon behaviours never ported**: empty key rejected, empty value lands as empty string, `=` inside a value, partly-numeric value stays a string, syntax-sensitive quoting preserved, malformed `--append` pair rejected (one of the three gap cases).
- **Four-channel rigour 23/29 (79%)** — most cases assert exit + stdout + stderr + resulting file bytes together.
- **Wildcard discipline near-perfect**: 1 wildcarded line in 451 asserted — no assertion-dodging.
- **One orphan case**: `date-looking-value-stays-a-string` maps to no etalon behaviour — extra coverage, not noise.

## Mutation kills — 12/15 (80%)

The frozen patch set mutates the CLI one defect at a time; a good corpus goes red each time.

Killed cleanly: every coercion drop (bool, int, float, null, YAML-1.1 quoting), macro left unrendered, macro error code change, malformed-pair code change, `--remove` no-op, diff suppression (23 cases red), summary rerouted to stdout (23 red), log line dropped.

**Survived — the report's core finding:**

| mutant | why it lived |
| --- | --- |
| `06_empty-value-becomes-null` | no case ever passes `key=` with an empty value |
| `07_first-equals-split-lost` | no case has `=` inside a value |
| `08_empty-key-accepted` | no case passes `=value` |

All three correspond exactly to unported etalon behaviours. The corpus isn't wrong anywhere — it's silent in three places, and the mutants walk through the silence.

## Review — 3.38/5, and both reviewers found the same thing

Two independent reviewers, identical rubric, diff + case-mapping table in hand.

**fable:medium — 3.75** (correctness 3, tests 3, code 4, scope 5), 6 findings. **codex — 3.0** (3/3/3/3), 6 findings.

Convergent findings, worst first:

1. **Cross-check overclaims.** Three cross-check rows map unit behaviours onto cases that never exercise them: empty-key rejection "covered by" `malformed-pair-is-an-error` (which passes `status`, not `=value`); `=`-in-value "covered by" `sets-a-key-to-a-literal-value` (no `=` in any value); empty-value "covered by" cases that never pass `key=`. Each corresponds to a surviving mutant — the document claims protection the corpus doesn't provide.
2. **DoD ticked over gaps.** M01's "every coercion family has a corpus case" checked while the partly-numeric and syntax-sensitive families have none (cross-check rows say "verified live" — exactly what the DoD disallows). M02's task 2.1 done without the malformed-`--append` case.
3. Minor: an unbalanced backtick mangles one rendered cross-check row.

Pattern in one sentence: **the code work is honest, the paperwork about the code work is not** — coverage loss laundered through a confident-looking cross-check.
