## The task

Every model runs the same groomed plan in its own throwaway clone off the same baseline: migrate `booping frontmatter-update`'s 571-line unit suite into txtar contract cases under `booping-python/e2e/cases/frontmatter-update/`, then delete the unit file once a written cross-check proves every CLI-observable behaviour it covered has a named corpus case. Three milestones — core CLI cases, list-ops and macro cases, deletion plus cross-check. The model never fixes tooling and never chooses scope; the runner drives the develop playbook and commits, the model writes the tests.
