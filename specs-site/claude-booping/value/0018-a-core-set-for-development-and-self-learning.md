On top of the framework ([value/0006](0006-a-constructor-not-a-fixed-solution.md)) booping ships a core set of playbooks for development — groom, develop, code-review, project-manager and self-learning ([value/0001](0001-curated-self-learning.md)). Those playbooks are also booping's own dogfooding (owner, 2026-10-17).

## In practice

A core playbook uses only mechanics a user playbook gets too; what the core set needs and the framework lacks becomes a framework mechanic, not a private shortcut.
