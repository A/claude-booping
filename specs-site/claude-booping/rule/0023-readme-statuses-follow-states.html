    Rule§

    Each playbook's states: block is the authority on its statuses. The README's Statuses section is a hand-maintained narrative over them, not rendered from them, so a change to a states: block revisits that section.

    [clarify] The source says "revisit"; whether it must land in the same commit is not named in the source.
